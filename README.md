# Dhamma Mirror

Dhamma Mirror is a local-first reflection tool for moments when anger, grief, pressure, or uncertainty may be narrowing what you can see.

It helps you pause, notice the body, write the thought, and answer careful questions before you act.

## What this is

Dhamma Mirror is a reflection tool. It asks questions. It does not give commands, make spiritual claims, replace a meditation teacher, provide therapy, provide crisis care, or make medical decisions.

It is independent and is not affiliated with VRI, dhamma.org, SuttaCentral, or any official Vipassana organisation.

## Who it helps

- someone about to send a reactive message;
- someone trying to think clearly during grief or conflict;
- a Vipassana practitioner who wants a quiet practice companion;
- a contributor who wants to improve a restrained, local-first reflection app.

## What you can do now

- check your body before you act;
- write a reactive message into a 24-hour vault;
- work through a conflict or difficult decision;
- read simple Pali term notes;
- track practice notes locally;
- export or review your own reflections where the app supports it.

## Safety boundaries

- This is not therapy, diagnosis, treatment, crisis care, or emergency support.
- If you may harm yourself or someone else, contact a real person and emergency or crisis support now.
- Ask a qualified teacher about meditation technique.
- Ask a qualified professional for mental health, medical, legal, financial, or safety decisions.
- Do not paste private third-party information, secrets, credentials, or legal documents into optional AI features.

## Run locally

```bash
git clone https://github.com/Almost-Magic/dhamma-mirror.git
cd dhamma-mirror
npm install
npm run dev
```

Then open the local URL shown by Vite, usually `http://localhost:5173`.

## Checks

```bash
npm test
npm run lint
npm run build
```
